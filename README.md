## 🔧 Frequently Asked Questions

**Q: Do I need an internet connection to use OpenEasyX?**
A: For the discovery feature, yes—because it searches online sources. But for playing media you already have downloaded, the library feature, and the organizer, no internet is required. You can enjoy your local collection fully offline

**Q: Will OpenEasyX slow down my computer?**
A: No. OpenEasyX is built to be lightweight. It only runs active processes when you are actively using it. Background downloads continue gently without hogging your bandwidth or CPU. Most users report no noticeable impact on everyday computer performance

**Q: Can I move my media folders later?**

A: Yes. Go to Settings > Library Location in the app. You can change the main folder path at any time. The software will re-scan and update all your organized metadata automatically. Moving the actual files physically on your hard drive is also fine—just point OpenEasyX to the new location after you move them

**Q: Does OpenEasyX support mobile devices or tablets?**
A: Currently, the official Windows desktop version is the primary release. However, since it is self-hosted, you can access your library from any device on your local network using a web browser if you enable the "Network Sharing" option in settings. This allows you to stream your media collection to phones, tablets, smart TVs, or other computers in your home without installing anything on those devices

**Q: Is there a cost?**
A: OpenEasyX is free to use for personal, non-commercial purposes. There is no paid tier, no premium subscription, no hidden charges. If you find it useful, consider contributing to the project or sharing it with friends—that is the best way to support ongoing development
